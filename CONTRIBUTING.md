# Contributing

The [README development guide](README.md#development-and-testing) contains the
build, test, and contribution workflow. Read the
[security and compatibility notes](README.md#protocol-overview) before changing
signing behavior. Include regression tests and describe migration consequences.

Never commit private keys, keystores, nonce journals, databases, or deployment
credentials.
The owner must settle [licensing](README.md#license) before enabling public contributions.
